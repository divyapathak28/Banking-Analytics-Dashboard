# Banking Analytics Dashboard

A banking analytics project built using **MySQL, SQL, and Power BI**.

## Overview

Banking data is cleaned and analyzed using SQL to understand customer transactions, spending, accounts, loans, and risk. The analysis is presented through an interactive Power BI dashboard.

## Key Areas

- Customer transaction and spending analysis
- Customer and account analysis
- Loan and risk analysis
- Customer segmentation
- Transaction trends
- Power BI dashboard reporting

## SQL Work

Includes data cleaning, duplicate checks, joins, aggregations, CTEs, window functions, views, and customer segmentation using `NTILE()`.

## Tools

**MySQL · SQL · Power BI**
